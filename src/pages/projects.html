yt_transcript_mcp

README Build log public

A Swift 6 MCP server that pulls YouTube transcripts through the InnerTube API. No Node, no Python. I built it because watching a video for information, even at double speed, is now the slow path, and turning it into text makes it something I can synthesize and act on straight away. Built in a day with a 27-issue review trail, in daily use since.

Shortcoming: one documented maintenance point, and it is not hosted, so it runs locally only.

chordsheet

248 tests

README Build log public

A web app for play-along guitar chord sheets, written in TypeScript with 248 tests. The interesting design constraint is legal, not technical: the AI assist only ever emits chord names and positions anchored to lyrics the user already has, never lyric content, which is why it works at all where a naive prompt gets refused.

Data flow

Verification: 248 tests across 17 files. From a one-paragraph idea to weekly rehearsal use in twelve days and 31 issues.

Shortcomings, stated in the README: Chromium-only folder save, no mobile layout, no undo, approximate voicings for unusual chords, and the tests stop at the UI boundary.

Jamie Brown, self-review

history-heatmap

1 file, 0 dependencies

README Build log Live demo public

An engine for visualizing historical population dynamics from AD 33 to the present, in one self-contained HTML file with no server and no dependencies. An analytical gaussian heat field evaluated per viewport at constant cost, mass-conserving anti-aliasing for city-scale overlays, and a hybrid model that blends hand-curated anchor data with logistic growth and diffusion. City lifecycle events are pure functions of the playhead, so scrubbing backward replays conquests in reverse with no extra state. The current Christianity and Islam dataset is the first lens rather than the point, and more population types are planned.

Data flow

Shortcoming, stated plainly: I have not audited the dataset's sources. The engineering I will defend. The numbers are unaudited estimates assembled from standard scholarship.

Jamie Brown, self-review
